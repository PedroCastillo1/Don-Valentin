# Manuales de uso — Don Valentín Digital

Un manual por puesto. Cada uno entra con su usuario en **/admin/ingresar** (desde la compu, la tablet o el celular) y ve solo lo que le corresponde.

| Manual | Para quién |
| --- | --- |
| [Encargado de Salón](encargado.md) | Reservas, salón, mesas y QR, carta y precios, parámetros, usuarios y medición del sitio. |
| [Mozo](mozo.md) | Abrir y liberar mesas, registrar llegadas, sentar grupos sin reserva, cargar pedidos y entregar. |
| [Cocina, parrilla y barra](sectores.md) | El panel de cada sector: qué entró, qué se está preparando y qué está listo. |
| [Administración](administracion.md) | Lo mismo que el Encargado, más la gestión de todos los usuarios y la auditoría. |
| [Comensal](comensal.md) | Cómo se reserva desde el sitio y cómo se pide con el QR de la mesa (para el cartel de la mesa o para explicar en el salón). |

Reglas para todos:

- La contraseña es personal: no se comparte ni se anota a la vista. Si alguien la olvida, el Encargado le crea una nueva.
- Al terminar el turno, tocá **Salir**. Si te equivocás 5 veces seguidas con la contraseña, la cuenta se bloquea unos minutos.
- El sistema se actualiza solo. Si algo no se ve al día, recargá la página.
